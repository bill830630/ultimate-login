# 終極登入 (Ultimate Login)

WooCommerce 用外掛：LINE / Google / Apple 社交登入，訂單狀態變更時透過 LINE 推播通知顧客，並可推播新訂單通知到管理員 LINE 群組。

## 功能

- LINE / Google / Apple OAuth 社交登入與帳號綁定
- 訂單狀態變更自動推播 LINE 通知給下單顧客
- 新訂單自動推播到管理員/員工共用的 LINE 群組
- 登入、註冊、購物車、結帳頁皆可顯示社交登入按鈕

詳細設定步驟（LINE/Google 憑證申請、群組通知設定等）請見外掛內建的 `readme.txt`，或安裝後到後台「終極登入」頁面查看完整說明。
